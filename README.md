# Fiestas Sanabria

Quiero crear una página web llamada “Fiestas Sanabria”, enfocada en publicar anuncios, noticias y artículos relacionados con fiestas, celebraciones, eventos y otros asuntos de interés de la zona de Sanabria.

1. Objetivo de la página

La web debe funcionar como un medio digital moderno de anuncios y publicaciones, donde cualquier persona pueda entrar y leer los contenidos publicados.

El objetivo principal es que la página tenga una apariencia elegante, moderna, premium y muy cuidada, pero sin perder la esencia de un periódico/revista digital.

Quiero que transmita la sensación de una web profesional, no de una plantilla genérica.

La experiencia debe ser:

Muy fluida.

Rápida.

Minimalista pero llamativa.

Fácil de utilizar.

Perfectamente adaptada a móvil, tablet y ordenador.

Con animaciones y transiciones sutiles y elegantes.

Con una excelente experiencia tanto en iPhone como en Android y navegadores de escritorio.

2. Página principal

La página de inicio debe mostrar los artículos/anuncios publicados recientemente.

Cada publicación debe aparecer como una tarjeta editorial, similar a la portada de un periódico o revista digital.

Cada tarjeta debe incluir:

Imagen de portada.

Título del artículo.

Fecha de publicación.

Una breve descripción o entradilla.

Posiblemente una categoría o etiqueta.

Un botón o indicación para acceder al artículo.

Las publicaciones más recientes deben tener mayor protagonismo.

Quiero una página visualmente atractiva, con una composición editorial moderna. No quiero una simple cuadrícula de tarjetas idénticas.

La página debe poder crecer con el tiempo y soportar muchas publicaciones sin que el diseño se vuelva desordenado.

3. Artículos / anuncios

Cuando un usuario pulse sobre una publicación, debe abrirse una página individual para ese artículo.

El artículo debe tener un diseño inspirado en un periódico/revista digital de alta calidad.

Debe incluir:

Título grande y elegante.

Imagen de portada destacada.

Fecha de publicación.

Categoría.

Cuerpo completo del artículo.

Subtítulos cuando sea necesario.

Imágenes adicionales dentro del artículo si las hay.

Enlaces si son necesarios.

Una navegación clara para volver a la página principal.

El diseño debe dar mucha importancia a la tipografía y a la lectura.

El texto debe ser cómodo de leer tanto en móvil como en ordenador.

4. Sistema de publicación

Necesito un sistema de administración privado.

Cualquier persona debe poder acceder a la web y leer los artículos, pero únicamente yo debo poder crear, editar o eliminar publicaciones.

Quiero que exista un panel de administración protegido mediante autenticación.

Desde este panel quiero poder:

Crear un artículo.

Editar artículos existentes.

Eliminar artículos.

Publicar/despublicar artículos.

Añadir título.

Añadir imagen de portada.

Añadir fecha.

Elegir categoría.

Escribir una descripción/entradilla.

Escribir el cuerpo completo del artículo.

Añadir imágenes al contenido.

Guardar borradores.

Publicar cuando esté preparado.

No quiero que los visitantes tengan ninguna posibilidad de modificar contenido.

La autenticación del administrador debe estar correctamente protegida. No debe existir ningún botón o ruta pública que permita a visitantes crear o modificar publicaciones.

5. Editor de artículos

El panel de administración debe tener un editor cómodo para crear artículos.

Quiero poder escribir el contenido de manera similar a un editor de periódico/blog moderno.

El editor debería permitir como mínimo:

Texto normal.

Títulos y subtítulos.

Negrita.

Cursiva.

Listas.

Enlaces.

Imágenes.

Saltos de párrafo.

Citas destacadas.

El resultado final debe conservar una estética editorial profesional.

6. Diseño visual

La identidad de Fiestas Sanabria debe ser elegante y moderna.

Quiero evitar:

Diseños excesivamente coloridos.

Estética infantil.

Exceso de animaciones.

Interfaces que parezcan una plantilla de IA.

Tarjetas genéricas con demasiados botones.

Elementos innecesarios.

La estética debería combinar:

Periódico tradicional + revista moderna + diseño web premium.

Usar una tipografía elegante para titulares y una tipografía muy legible para el cuerpo del texto.

La paleta debe ser sofisticada y relacionada con Sanabria, pudiendo utilizar tonos como:

Negro.

Blanco/crema.

Gris.

Verde oscuro.

Algún color de acento muy sutil.

El logo/título “Fiestas Sanabria” debe tener bastante presencia en la cabecera.

7. Cabecera

Crear una cabecera limpia y profesional.

Debe incluir:

Fiestas Sanabria

Y navegación sencilla, por ejemplo:

Inicio

Fiestas

Eventos

Noticias

Otros

La navegación debe adaptarse correctamente a móvil mediante un menú hamburguesa.

La cabecera puede permanecer fija o utilizar un comportamiento elegante al hacer scroll, siempre que no perjudique la experiencia.

8. Animaciones

Quiero que la página se sienta especialmente fluida.

Utilizar animaciones modernas y sutiles, por ejemplo:

Aparición progresiva de artículos.

Hover suave sobre las imágenes.

Transiciones entre páginas.

Animaciones ligeras al hacer scroll.

Microinteracciones en botones.

Transiciones suaves en el menú.

Las animaciones deben ser rápidas y elegantes. No quiero animaciones exageradas que hagan que la web parezca lenta.

9. Responsive

La página debe estar diseñada mobile-first.

Debe funcionar perfectamente en:

iPhone.

Android.

Tablets.

Mac.

Windows.

Chrome.

Safari.

Firefox.

Edge.

Especial atención a:

Tamaños de texto.

Imágenes.

Menús.

Márgenes.

Velocidad.

Lectura de artículos largos.

Elementos táctiles.

10. Página de inicio vacía

Si todavía no existen publicaciones, no quiero que aparezca una página rota o vacía.

Debe aparecer un estado vacío elegante indicando que todavía no hay publicaciones disponibles.

11. SEO y accesibilidad

La web debe estar preparada desde el principio para SEO.

Implementar correctamente:

Títulos de página.

Meta descriptions.

URLs limpias.

Open Graph para compartir artículos.

Etiquetas semánticas.

Alt text para imágenes.

Estructura correcta de headings.

Los artículos deberían poder compartirse fácilmente mediante enlaces.

12. Arquitectura y seguridad

La web debe separar claramente:

Parte pública

Cualquier persona puede acceder.

Cualquier persona puede leer los artículos.

Nadie excepto el administrador puede modificar contenido.

Parte privada

Panel de administración.

Autenticación.

Crear/editar/eliminar publicaciones.

Gestión de imágenes y contenido.

No quiero que la seguridad dependa simplemente de ocultar botones en el frontend. Los permisos deben estar correctamente protegidos en el backend/base de datos.

13. Base de datos

Crear una estructura de datos adecuada para almacenar las publicaciones.

Cada publicación debería poder contener como mínimo:

ID.

Título.

Slug.

Imagen de portada.

Descripción.

Contenido.

Categoría.

Fecha de publicación.

Fecha de modificación.

Estado (borrador/publicado).

Autor/admin.

La estructura debe permitir añadir nuevas funcionalidades en el futuro.

14. Escalabilidad

Aunque inicialmente será una página sencilla, quiero que la arquitectura permita añadir posteriormente funciones como:

Buscador.

Categorías.

Filtros.

Eventos destacados.

Calendario de fiestas.

Galería de imágenes.

Compartir artículos.

Artículos destacados.

Sistema de noticias recientes.

Estadísticas del administrador.

No es necesario implementar todas estas funciones ahora, pero la arquitectura debe permitir añadirlas posteriormente sin tener que reconstruir toda la aplicación.

15. Experiencia general

Quiero que cuando una persona entre en Fiestas Sanabria tenga la sensación de estar entrando en un medio digital local profesional.

La prioridad debe ser:

Diseño → velocidad → fluidez → legibilidad → facilidad de administración.

No quiero simplemente una web funcional. Quiero una web que destaque visualmente y que pueda convertirse en la página de referencia para consultar anuncios, fiestas, celebraciones y acontecimientos de Sanabria.

16. Importante

Antes de terminar, comprueba que:

La página pública funciona correctamente.

Los artículos se pueden abrir individualmente.

El panel de administración está protegido.

Un visitante normal NO puede crear, modificar ni eliminar artículos.

El administrador puede crear, editar, publicar y eliminar artículos.

Las imágenes funcionan correctamente.

El diseño es completamente responsive.

La web funciona correctamente en Safari y Chrome.

No existen errores de consola importantes.

Las transiciones y animaciones no perjudican el rendimiento.

Los artículos tienen URLs individuales y compartibles.

La estructura está preparada para poder añadir nuevas funcionalidades en el futuro.

Construye primero una versión completa y funcional de la aplicación, con especial atención al diseño visual y a la experiencia móvil. No quiero una landing page estática: quiero una web real con sistema de publicaciones y panel privado de administración.
